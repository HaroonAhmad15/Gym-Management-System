## Description
A complete Gym Management System built with Windows Forms and MySQL database.
Uses 3-tier architecture with Models, Repository, and Forms layers.

## Features
- Member Management (Add, Edit, Delete, Search)
- Membership Plans (Monthly, Quarterly, Yearly)
- Payment Tracking and Revenue Reports
- Attendance Marking with duplicate prevention
- Trainer Management
- Dashboard with real-time statistics
- Reports with expiry alerts

## Technologies Used
- C# Windows Forms (.NET Framework 4.7.2)
- MySQL Database 8.0
- ADO.NET for database connectivity
- Repository Pattern architecture
